UP AND RUNNING IN A MINUTE

Install Rantube

Android asks you to approve apps downloaded outside the Play Store. The first launch takes a little longer while Rantube prepares its download engine.

  1. 01
    Download the APK

    Tap the download button above and wait for the file to finish.

  2. 02
    Allow this browser

    If prompted, choose Settings and allow your browser to install apps.

  3. 03
    Install and open

    Tap the downloaded file, choose Install, then open Rantube.
